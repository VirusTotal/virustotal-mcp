# vt-mcp 0.8.3 — PyPI distribution and local discovery

Version 0.8.3 prepares the Apache-2.0 package for distribution as `vt-mcp` on PyPI. The README provides an isolated installation command, public setup links and the ownership marker used by the MCP Registry. Author metadata identifies VirusTotal; existing copyright and license notices remain included.

```bash
uv tool install --python 3.12 --default-index https://pypi.org/simple 'vt-mcp==0.8.3'
vt-mcp --version
```

Setup guides remain ordered [Agy](https://ai.virustotal.com/connect/mcp?client=agy&transport=stdio), [Claude Code](https://ai.virustotal.com/connect/mcp?client=claude), then [Codex](https://ai.virustotal.com/connect/mcp?client=codex). A free VTAI token is required; a personal VirusTotal API key is not.

The corporate Registry manifest adds the PyPI stdio package alongside the existing HTTP endpoint. Registry publication is separate from this release and requires matching public PyPI files first. The previous corporate Registry version and retired personal entry are preserved.

This release keeps the tools, runtime dependencies, submission limits, authentication and receipt recovery unchanged. It does not deploy a new VTAI backend. Existing native-client validation keeps its original version and environment scope; installation of these exact assets is checked separately.

GitHub release, PyPI upload and Registry publication are separate steps: a GitHub release alone does not prove PyPI or Registry availability. The PyPI workflow publishes the reviewed wheel and source archive without rebuilding and records both source and publishing provenance. Public installation becomes available when those files are present on PyPI.

The corporate repository remains private. Wheel and source archive distributed through PyPI are public; internal development notes are excluded. Previous releases, tags and assets are retained, including the original MIT releases through 0.8.0.
