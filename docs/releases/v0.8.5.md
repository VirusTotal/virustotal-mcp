# vt-mcp 0.8.5

Missing reports now include a supported next step for each indicator and transport, without treating missing intelligence as safety. Local file guidance uses `submit_local_file` or `submit_file`; URL guidance offers separate domain evidence. The tool set and permissions are unchanged.

Quota errors include a closed `quota_source` when VTAI provides it and recommend retaining credentials, waiting and deduplicating lookups. The local package now preserves valid numeric and HTTP-date `Retry-After` on 503 responses as well as 429, including analysis reads. An uncertain submission still returns recovery instructions and is never replayed automatically.

```sh
uv tool install --upgrade --python 3.12 --default-index https://pypi.org/simple 'vt-mcp==0.8.5'
```

Existing clients with a pinned `uvx` command must update that pin. Remote HTTP clients use the deployed service. Retain tokens and local submission receipts when upgrading. See the [setup guide](https://ai.virustotal.com/connect/mcp) for managed configuration checks and updates, ordered Agy, Claude Code, Codex.

Validation covers error contracts, retries, analysis recovery and the packaged MCP transport. It does not certify every model workflow. Apache-2.0; prior releases remain unchanged.
