# vt-mcp 0.9.2

Corrects `get_submission` discovery metadata to advertise `openWorldHint: false`.
The tool reads only the current account's submission receipt, without an upstream
VirusTotal call. The correction covers file and network receipts in embedded
servers and local stdio.

Tool names, argument schemas, receipt behavior and other annotations remain
unchanged. Existing file, network-analysis and report calls remain compatible.

```sh
uv tool install --upgrade --python 3.12 --default-index https://pypi.org/simple 'vt-mcp==0.9.2'
```

Hosted deployments receive this metadata correction when their operator upgrades
the embedded package. See [submission and recovery](https://github.com/VirusTotal/virustotal-mcp/blob/main/docs/analysis.md).
