# vt-mcp 0.8.4 — Native Windows submissions

Both local MCP submission tools now work on Windows. Submission references use private local NTFS storage, exclusive creation and synchronized writes before dispatch. A repeated or uncertain submission recovers through GET, including after a process restart; it does not repeat the POST. Binary file copies preserve their original bytes and reject reparse points.

The local MCP server supports Linux, macOS and Windows. Linux/macOS retain the POSIX storage implementation. Windows receipt state requires local NTFS; network shares and alternate streams are unsupported. The separate `vt-mcp guard` command remains Linux-only.

```sh
uv tool install --python 3.12 --default-index https://pypi.org/simple 'vt-mcp==0.8.4'
```

Use the [setup guide](https://ai.virustotal.com/connect/mcp) for client configuration, in Agy → Claude Code → Codex order. The package keeps the same eight local tools, runtime dependencies, account rights and quotas. Native OS protocol checks are separate from commercial-client and model validation.

Apache-2.0; earlier release files and licenses remain unchanged.
