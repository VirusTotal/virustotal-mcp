# 0.9.7

File submission errors distinguish VTAI contribution limits from report-query
quota. The client recognizes the closed contribution-limit and admission-service
errors, preserves their retry delay and excludes provider error text.

Submission POSTs are never retried automatically. The local wrapper and CLI keep
their existing durable reference after a rejected attempt; a later call for the
same hash recovers the receipt instead of repeating the upload. This release does
not change that recovery policy.
