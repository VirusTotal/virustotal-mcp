# vt-mcp 0.9.5

Fixes a relative documentation link in the package description and updates the documented installation version. Version 0.9.4's PyPI preflight rejected that link before upload; its existing GitHub release remains unchanged.

The runtime is identical to 0.9.4. When a client cannot transmit file bytes, missing-file guidance offers the existing VirusTotal web upload page, followed by a hash report lookup. Clients that can supply the bytes retain the existing submission tools. A web upload creates no VTAI receipt or registered analysis ID.

Public-sharing disclosure, sensitive-content guidance and host permissions still apply. This alternative does not bypass permissions or quota errors. Every repeated report query continues to count, including missing reports and cache hits. Tool catalogs, schemas, authentication and submission behavior are unchanged.

```sh
uv tool install --upgrade --python 3.12 --default-index https://pypi.org/simple 'vt-mcp==0.9.5'
```

Apache-2.0; earlier releases remain unchanged.
