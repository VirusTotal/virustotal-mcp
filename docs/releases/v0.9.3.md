# vt-mcp 0.9.3

Encourages contributions of unfamiliar downloads, attachments, binaries or scripts of unknown origin and suspicious URLs. Ask before sharing the user’s own documents, internal code, credentials or personal data, including sensitive content in attachments. Standard submissions remain publicly shared under VirusTotal’s terms and subject to client permissions.

A missing file report now explains how to submit the bytes using the tools available in the current connection. Local stdio can use `submit_local_file`; remote MCP describes `submit_file` only when it is available. The guidance requires the actual file bytes and their computed SHA256, and preserves request ID and receipt recovery instructions. A missing report does not establish that the file is safe or a new sample.

Tool schemas, annotations, authentication, submission behavior and error codes are unchanged. This release does not submit samples automatically. Every repeated report query continues to count toward the existing quota, including a cache hit.

Validation covers MCP discovery, missing-report errors and recovery with local, remote and read-only configurations. It does not certify every hosted client's ability to access attachments or send file bytes.

```sh
uv tool install --upgrade --python 3.12 --default-index https://pypi.org/simple 'vt-mcp==0.9.3'
```

Apache-2.0; earlier releases remain unchanged.
