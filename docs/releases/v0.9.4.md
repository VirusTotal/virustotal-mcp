# vt-mcp 0.9.4

When a client cannot transmit file bytes, missing-file guidance offers the existing VirusTotal web upload page, followed by a hash report lookup. Clients that can supply the bytes retain the existing submission tools. A web upload creates no VTAI receipt or registered analysis ID.

Public-sharing disclosure, sensitive-content guidance and host permissions still apply. The alternative does not bypass permissions or quota errors. Every repeated report query continues to count, including missing reports and cache hits; report availability after an upload is not guaranteed immediately.

Tool catalogs, schemas, authentication and submission behavior are unchanged. No new upload page, endpoint or automatic submission is introduced. Validation covers local, remote and read-only MCP guidance and the shared REST error guidance; it does not establish attachment transfer in every hosted client.

```sh
uv tool install --upgrade --python 3.12 --default-index https://pypi.org/simple 'vt-mcp==0.9.4'
```

Apache-2.0; earlier releases remain unchanged.
