# vt-mcp 0.8.2 — Apache-2.0 corporate release

Version 0.8.2 completes the Apache-2.0 distribution from
[VirusTotal/virustotal-mcp](https://github.com/VirusTotal/virustotal-mcp).
The wheel and source distribution include LICENSE, NOTICE and LICENSES/MIT.txt.
The MIT notice preserves attribution and permissions for pre-existing material;
new contributions are licensed under Apache-2.0. Previously published versions
through 0.8.0 retain their MIT license, tags and original distribution files.

The release pilot now validates the corporate repository identity and records
that repository in its evidence. The previous hardcoded personal-repository
check stopped v0.8.1 before calling VTAI; that tag remains available without
published package assets. Version 0.8.2 uses a new tag and its own verified CI
artifacts. Both allowlisted public-fixture gates must pass before publication.

The package preserves the runtime code and dependencies from 0.8.0: seven common
MCP tools, the additional local-file tool over stdio, authentication, submission
limits and receipt recovery. This release does not deploy a new VTAI backend or
change the hosted endpoint. Existing native-client validation keeps its original
version and environment scope.

The corporate repository remains private. Public installation continues through
the [MIT v0.8.0 release](https://github.com/king-tero/vt-mcp/releases/tag/v0.8.0)
until the corporate distribution is public. The corporate registry manifest
prepares version 0.8.2; the existing personal registry entry remains at 0.8.0
until its separate cutover.

For setup, follow
[Agy](https://github.com/VirusTotal/virustotal-mcp/blob/v0.8.2/docs/clients.md#antigravity-cli-agy),
[Claude Code](https://github.com/VirusTotal/virustotal-mcp/blob/v0.8.2/docs/clients.md#claude-code),
then [Codex](https://github.com/VirusTotal/virustotal-mcp/blob/v0.8.2/docs/clients.md#codex-cli--remote-http).
