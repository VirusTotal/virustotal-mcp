# vt-mcp 0.9.1

Makes the analysis and recovery documentation link work from the PyPI project page. This is the PyPI release of the network analysis capabilities introduced in 0.9.0; runtime code is unchanged.

URL submission and domain/IP reanalysis require the compatible VTAI network-analysis service. Existing file and report calls remain compatible.

```sh
uv tool install --upgrade --python 3.12 --default-index https://pypi.org/simple 'vt-mcp==0.9.1'
```

See [analysis and recovery](https://github.com/VirusTotal/virustotal-mcp/blob/main/docs/analysis.md#network-analysis-and-recovery).
