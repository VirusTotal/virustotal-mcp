# vt-mcp 0.8.1 — Apache-2.0 and corporate distribution

Version 0.8.1 distributes vt-mcp under the Apache License, Version 2.0, with
project metadata pointing to
[VirusTotal/virustotal-mcp](https://github.com/VirusTotal/virustotal-mcp).

The wheel and source distribution include the full Apache license, the existing
copyright attribution in NOTICE, and the original MIT notice for pre-existing
material in LICENSES/MIT.txt. New contributions are not offered under an
alternative MIT license. Previously published versions through 0.8.0 retain
their MIT license, tags and original distribution files.

This release changes licensing and distribution metadata. It preserves the
seven common MCP tools, the additional local-file tool over stdio, dependencies,
authentication behavior, submission limits and recovery semantics. It does not
deploy a new VTAI backend or change the hosted endpoint. Existing native-client
evidence retains its recorded version and environment scope.

The corporate repository remains private during preparation. Public installation
continues to use the
[existing v0.8.0 release](https://github.com/king-tero/vt-mcp/releases/tag/v0.8.0)
until corporate distribution is public. The prepared corporate registry manifest
uses version 0.8.1; the existing personal registry entry remains at 0.8.0 until
its separate cutover.

Follow the guides for
[Agy](https://github.com/VirusTotal/virustotal-mcp/blob/v0.8.1/docs/clients.md#antigravity-cli-agy),
[Claude Code](https://github.com/VirusTotal/virustotal-mcp/blob/v0.8.1/docs/clients.md#claude-code),
and [Codex](https://github.com/VirusTotal/virustotal-mcp/blob/v0.8.1/docs/clients.md#codex-cli--remote-http),
in that order, when accessing this source release. Package publication does not
establish a new native-client validation or a corporate registry publication.
