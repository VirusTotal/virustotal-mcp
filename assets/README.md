# VirusTotal brand assets

Use [virustotal-icon-512.png](virustotal-icon-512.png) for directory uploads and
[virustotal.svg](virustotal.svg) when a vector image is supported. Both are square
and place the existing VirusTotal mark on a white background.

The mark reproduces the geometry and color of the [VirusTotal AI logo](https://ai.virustotal.com/logo.svg).
Only padding was added for square icon fields. The PNG is 512 × 512 pixels.

These files identify the official VirusTotal integration. The repository's
software license does not grant rights to VirusTotal trademarks.
